# Rust

Rust se distribuye principalmente bajo MIT o Apache-2.0, a elección del usuario, con componentes sujetos a otros avisos. La licencia de Rust corresponde a sus autores y no sustituye la licencia del código propio de Crablo.

- [LICENSE-MIT](LICENSE-MIT): aviso de The Rust Project Contributors y texto MIT, según el [repositorio oficial](https://github.com/rust-lang/rust/blob/main/LICENSE-MIT).
- [LICENSE-APACHE](LICENSE-APACHE): texto Apache-2.0 de la distribución local de Rust.
- [COPYRIGHT-library.html](COPYRIGHT-library.html): avisos de la biblioteca estándar de la distribución local, incluyendo sus componentes de terceros.
- [licenses](licenses/): textos de licencia suministrados por esa distribución.
- [VERSION.txt](VERSION.txt): versión de la herramienta de la que se copiaron los avisos locales.
- [UPSTREAM-README.md](UPSTREAM-README.md): README original de esa distribución.

Referencia oficial: [licencias de Rust](https://rust-lang.org/policies/licenses/). Si se cambia de toolchain, deben actualizarse los avisos de la biblioteca estándar a los de esa versión.
